## Description
Records or corrects one creature's complete current/maximum D&D 2024 Hit Point state with fixed SRD 5.2.1 attribution. Administrative state only; it does not apply damage, healing, temporary Hit Points, or zero-HP consequences.

## Matches

set hit points
correct hit points
