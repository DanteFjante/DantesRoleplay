## Description
Conventions for stable ids and human-readable names on entities and component definitions.

## Instructions
1. Use stable dotted lowercase ids. 2. Keep display names concise. 3. Never reuse an id for a different concept.

## Constraints
Never reuse ids; do not use spaces or uppercase letters in ids.
