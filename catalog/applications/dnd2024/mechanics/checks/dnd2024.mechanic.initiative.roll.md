## Description

Resolves one effect-free D&D 2024 Initiative count from Dexterity. An actor with exactly one
canonical Alert entitlement may explicitly opt into Initiative Proficiency; the mechanic derives
the current Proficiency Bonus from authoritative character level. When the actor has an active
canonical rest episode, the result also carries a validated interruption plan for the encounter
materializer to apply atomically with Initiative participation.
