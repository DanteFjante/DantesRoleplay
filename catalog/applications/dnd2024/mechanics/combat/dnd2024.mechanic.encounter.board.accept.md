## Description

Commits an explicitly GM-reviewed structured board and an optional finalized aligned PNG
reference through the existing confirmed action transaction. Revalidates the active scene,
board revision, geometry, occupied squares and closed metadata. Existing media is retained.
This operation never changes initiative, turn ownership, positions or turn budgets.
Generation is not acceptance. An AI must never confirm its own proposed map.

## Matches

accept the reviewed combat map
commit this explicitly approved encounter layout
