## Description

Moves the active participant along one exact grid path. The mechanic validates the current turn,
board and position revisions, footprint bounds, blocking obstacles, occupied spaces, terrain cost,
and path adjacency. Its pinned turn-budget child authorizes and records the exact metric movement
cost, so position and movement spend commit atomically under one direct action.

## Matches

move a combatant on the tactical board
move my token along this path
spend movement and update position
