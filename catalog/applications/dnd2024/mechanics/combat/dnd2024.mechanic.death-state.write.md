## Description
Begins, corrects, or ends a character's dying/death-save state using the current
`dnd2024.character.death-saves` component. It does not apply damage or resolve a death save.

## Matches
begin death state
correct death state
end death state

## Requirements
```json
{"roles":{"subject":{"components":[],"description":"The character whose dying/death-save state is transitioned."}},"inputSchema":{"anyOf":[{"type":"object","additionalProperties":false,"required":["mode"],"properties":{"mode":{"type":"string","enum":["begin","end"]}}},{"type":"object","additionalProperties":false,"required":["mode","successes","failures","stable","dead"],"properties":{"mode":{"const":"correct"},"successes":{"type":"integer","minimum":0,"maximum":3},"failures":{"type":"integer","minimum":0,"maximum":3},"stable":{"type":"boolean"},"dead":{"type":"boolean"}}}]}}
```

## Input and result
Use `{"mode":"begin"}`, `{"mode":"end"}`, or correction with exactly
`mode`, `successes`, `failures`, `stable`, and `dead`. Stable resets tallies; terminal dead state
cannot be cleared. A valid existing `lastChangeRef` is preserved. Effects are typed add, set, or
remove operations on the death-saves component.
