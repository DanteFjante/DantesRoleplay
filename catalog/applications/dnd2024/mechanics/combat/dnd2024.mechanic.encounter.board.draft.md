## Description

Creates an inert GM-only layout from the exact active campaign encounter and location.
A bounded deterministic seed controls presentation geometry. Current occupied squares and
a central passage remain clear. The background request is private and never rules authority.

## Matches

generate a draft combat map
preview a seeded encounter layout
