## Description

Adds or corrects one participation's authoritative grid anchor, footprint, elevation, and audience
visibility. Placement validates board bounds, blocking obstacles, occupied footprints, encounter
membership, and exact board and position revisions. It does not spend movement or change a turn.

## Matches

place a combatant on the encounter board
set a participant tactical position
correct a token position
