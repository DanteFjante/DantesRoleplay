## Description

Validates a creature's generic defense state and returns final Armor Class without storing the
derived number. Monk Unarmored Defense is an explicit character selection layered over the
ordinary unarmored basis; the retired transient Monk basis ID is read only for safe migration.

## Matches

read armor class
derive armor class
