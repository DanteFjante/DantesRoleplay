## Description

Projects one exact World root or location plus one stable, bounded page of its immediate
non-archived locations. Containment owns membership and hierarchy; identifier spelling is never
interpreted. The host-selected audience is applied before paging, and the response source revision
binds every continuation read to the same authorized containment snapshot. When the bounded
depth-one host projection proves that a returned child has no contained entities, the projection
marks that child scope as known empty so a reader does not need a second empty-scope request.

## Matches

show one world location scope page
continue an immediate location directory
