## Description

Advances the one base-application world clock installed in the D&D application. It preserves the
calendar, advances only by a closed positive minute input, and emits the generic typed clock event
inside the same idempotent application transaction.

## Matches

advance D&D world time
pass time in the campaign world
advance the campaign clock
