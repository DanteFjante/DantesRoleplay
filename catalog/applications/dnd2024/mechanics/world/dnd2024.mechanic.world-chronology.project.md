## Description

Projects a source-fenced page of dated records from the exact selected campaign's world using one immutable graph.
Visibility, active/archive state, calendar membership and subject-world checks are application
rules here, never endpoint branches. Player output excludes GM records and canonical subject
identities. Invalid display fields remain local; scope, audience, graph and serialized page bounds
fail closed. A continuation cursor carries two independent fences: the host-reserved source
revision from the preceding registered-query response and this graph's declared source revision.
