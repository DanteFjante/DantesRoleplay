## Description

Projects the selected World's bounded location hierarchy, recurring people, creatures, and
DM-only holdings from declared containment and component identity. Identifier spelling is never
used to infer membership or record kind. Media remains a separate authorized batch read.

## Matches

list people in the selected world
show dm holdings by location
