## Description

Creates the first active session for a campaign that has never retained a session. Later session
lifecycle remains governed by the general session contract.

## Matches

start the first campaign session
begin campaign play
open session one

## Requirements

```json
{"roles":{"campaign":{"components":["game.core.campaign.root"],"includeRelationships":true,"description":"The active campaign with no retained sessions."}},"effectComponentIds":["game.core.campaign.session"]}
```

## Input

Supply exactly `sessionId`, beginning with `session.`. The mechanic fixes ordinal to 1 and status
to `active`.
