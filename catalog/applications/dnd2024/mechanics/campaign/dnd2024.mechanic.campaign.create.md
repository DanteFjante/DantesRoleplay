## Description

Creates one active D&D 2024 campaign root in an existing World and records its reviewed starting
location. It never creates or changes World content.

## Matches

create a campaign in an existing world
start a reviewed campaign
set up a campaign at a known location

## Requirements

```json
{"roles":{"world":{"components":["game.core.world.root"],"includeContents":true,"contentsDepth":4,"contentsRelevantToRoles":["location"],"includeRelationships":true,"description":"The existing active World that owns the campaign setting and its bounded containment tree."},"location":{"components":["game.core.world.location"],"includeRelationships":true,"description":"The existing starting location, already contained anywhere beneath or linked to the selected World."}},"effectComponentIds":["game.core.campaign.root"],"inputSchema":{"type":"object","additionalProperties":false,"required":["campaignId","title","premise","partyGoals","toneAndBoundaries","reviewFingerprint"],"properties":{"campaignId":{"type":"string","minLength":1,"maxLength":200},"title":{"type":"string","minLength":1,"maxLength":160},"premise":{"type":"string","minLength":1,"maxLength":1000},"partyGoals":{"type":"array","items":{"type":"string","minLength":1,"maxLength":500},"minItems":1,"maxItems":20,"uniqueItems":true},"toneAndBoundaries":{"type":"array","items":{"type":"string","minLength":1,"maxLength":500},"minItems":1,"maxItems":20,"uniqueItems":true},"reviewFingerprint":{"type":"string","minLength":64,"maxLength":64}}}}
```

## Input

Supply exactly `campaignId`, `title`, `premise`, `partyGoals`, `toneAndBoundaries`, and the
lowercase SHA-256 `reviewFingerprint` of the reviewed blueprint. IDs must begin with `campaign.`.
