## Description

Publishes up to 24 party-visible or GM-only suggestions matching the campaign's exact current
scene. These are presentation hints, never authoritative player choices.

## Matches

show what can be done in the current scene
update current tab actions
publish scene affordances

## Requirements

```json
{"roles":{"campaign":{"components":["game.core.campaign.root","game.core.campaign.current-scene"],"optionalComponents":["game.core.campaign.scene-affordances"],"includeRelationships":true,"description":"The active campaign with the exact current scene."}},"effectComponentIds":["game.core.campaign.scene-affordances"]}
```

## Input

Supply exactly `items`, an array of unique `{key,label,summary,visibility}` objects. Visibility is
`party` or `gm`; an empty array is valid.
