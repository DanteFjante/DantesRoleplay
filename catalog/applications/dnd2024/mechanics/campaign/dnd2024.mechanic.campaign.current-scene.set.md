## Description

Records an exact existing location as the campaign's current scene. Use `record` once and `move`
only after a scene exists.

## Matches

set the current campaign scene
enter a location
move the party to a location

## Requirements

```json
{"roles":{"campaign":{"components":["game.core.campaign.root"],"optionalComponents":["game.core.campaign.current-scene"],"includeRelationships":true,"description":"The active campaign whose scene changes."},"world":{"components":["game.core.world.root"],"includeContents":true,"contentsDepth":4,"contentsRelevantToRoles":["location"],"includeRelationships":true,"description":"The campaign's exact active World containing the destination."},"location":{"components":["game.core.world.location"],"includeRelationships":true,"description":"The exact existing destination location contained by the selected World."}},"effectComponentIds":["game.core.campaign.current-scene"]}
```

## Input

Supply exactly `mode`, either `record` for the first scene or `move` thereafter.
