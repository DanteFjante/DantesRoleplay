## Description

Creates one active participation identity for an existing actor and links it to the campaign.

## Matches

attach a character to a campaign
add a player character to the party
record campaign participation
form a party from existing characters
add an existing actor as a party member

## Requirements

```json
{"roles":{"campaign":{"components":["game.core.campaign.root"],"includeRelationships":true,"description":"The active campaign receiving the character."},"actor":{"components":[],"includeRelationships":true,"description":"The exact existing actor joining the campaign."}},"effectComponentIds":["game.core.campaign.character-participation"],"inputSchema":{"type":"object","additionalProperties":false,"required":["participationId"],"properties":{"participationId":{"type":"string","minLength":1,"maxLength":200}}}}
```

## Input

Supply exactly `participationId`, beneath the campaign ID as `campaign....participation....`.
