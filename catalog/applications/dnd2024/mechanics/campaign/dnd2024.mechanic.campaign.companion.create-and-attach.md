## Description

Creates one narrative companion at the campaign's exact current location and atomically adds the
companion to the campaign's derived active-party roster. This establishes an actor identity,
traveller state, motive, presence, and campaign participation. It deliberately does not invent a
D&D character sheet, class, species, equipment, abilities, or player ownership.

## Matches

create a companion and add them to the party
form a party with a new companion
recruit a simulated campaign companion
add a narrative party member at the current scene

## Requirements

```json
{"roles":{"campaign":{"components":["game.core.campaign.root","game.core.campaign.current-scene"],"includeRelationships":true,"description":"The active campaign whose current scene receives the companion."},"world":{"components":["game.core.world.root"],"includeContents":true,"contentsDepth":4,"contentsRelevantToRoles":["location"],"includeRelationships":true,"description":"The existing World containing the campaign location."},"location":{"components":["game.core.world.location"],"includeRelationships":true,"description":"The exact current scene location, already contained beneath the selected World."}},"effectComponentIds":["game.core.world.traveller","game.core.world.motive","game.core.campaign.character-participation"],"inputSchema":{"type":"object","additionalProperties":false,"required":["actorId","name","motiveSummary"],"properties":{"actorId":{"type":"string","minLength":1,"maxLength":200},"name":{"type":"string","minLength":1,"maxLength":400},"motiveSummary":{"type":"string","minLength":1,"maxLength":1000}}}}
```

## Input

Supply exactly `actorId`, `name`, and `motiveSummary`. The actor ID must begin with `actor.`. The
action derives the campaign-owned participation ID and creates one party-visible active motive.
