## Description

Restores a bounded number of object Hit Points and emits authoritative before/after provenance.
Cost-free repairs are limited to non-destroyed objects. Rebuilding a destroyed object requires
one or more settlement receipts from the Slice 14 materials, service, cost, and elapsed-time owners.

## Matches

repair a damaged object
partially or fully repair an item trap vehicle or scenery
