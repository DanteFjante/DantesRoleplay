## Description

Commits zero Hit Points and destruction together with the exact owned consequence effects present
on the object. Special magic-item requirements fail closed unless the authored requirement is the
currently executable unconditional predicate and the caller establishes it.

## Matches

destroy an object at zero hit points
apply object destruction consequences
