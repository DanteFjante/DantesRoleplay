## Description

Materializes only the exact species and background references already preserved by a valid,
immutable basic character-creation record. An absent origin component is added; an identical
component is an idempotent no-op; any conflicting origin fails closed. The mechanic never edits
the creation record and never infers or substitutes a character choice.

## Matches

materialize recorded character origin
repair missing species and background selections
restore origin from character creation evidence
