## Description

Reads exact SRD carry and drag/lift/push capacity, converted to canonical kilograms, from one
registered creature object and the separately composed physical-burden result.

## Matches

derive carrying capacity

## Requirements

```json
{"roles":{"creature":{"components":["dnd2024.creature.ability-scores","dnd2024.creature.body"],"description":"Creature whose exact Strength, Size, and bounded physical burden are derived."}},"snapshotObjects":{"creature":{"qualifiedId":"dnd2024.object.carrying-capacity-creature","version":2,"contentFingerprint":"828BC5D694102E129C870CA49291424ABFB79F8BDE17A169037CA26B9D5A3DC1","roleBindings":{"creature":{"role":"creature"}},"referenceComponentIds":[],"maximumItems":1}},"children":{"burden":{"mechanicId":"dnd2024.mechanic.item-burden.read","roleBindings":{"root":"creature"},"inheritInput":false,"input":"{}","mechanicVersion":1,"contentFingerprint":"CC7435DB5473AD327D4EFB559D0283CB747454AC85995A09A020DB68DF9A33E4"}},"inputSchema":{"type":"object","additionalProperties":false,"minProperties":0,"maxProperties":0}}
```

## Input and result

Pass exactly `{}`. The mechanic derives Strength and Size from the registered creature object,
consumes exactly one matching burden child result, applies the SRD Size multiplier, and converts the
exact pounds formula to kilogram measures. It reports carry, drag/lift/push, burden, and whether the
burden is within capacity without changing Speed or inventory.

## Minimal object-input example

Declare only the source components on the ordinary role, bind an exact registered snapshot object
to that role, and read only the materialized value in JavaScript. The host removes the consumed raw
components before sandbox execution. Keep independently reusable graph work in a pinned child
mechanic instead of projecting the same inventory into the parent again.

```json
{"roles":{"creature":{"components":["dnd2024.creature.ability-scores","dnd2024.creature.body"]}},"snapshotObjects":{"creature":{"qualifiedId":"dnd2024.object.carrying-capacity-creature","version":2,"contentFingerprint":"828BC5D694102E129C870CA49291424ABFB79F8BDE17A169037CA26B9D5A3DC1","roleBindings":{"creature":{"role":"creature"}},"referenceComponentIds":[],"maximumItems":1}}}
```

```javascript
var creatureObject = ctx.objects.creature;
var strength = creatureObject.value.abilityScores.scores["dnd2024.vocabulary.ability.strength"];
var sizeId = creatureObject.value.sizeRef.entityId;
```
