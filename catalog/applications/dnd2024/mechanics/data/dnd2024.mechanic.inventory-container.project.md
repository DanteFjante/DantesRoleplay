## Description

Projects the audience-authorized character's physical containment tree and exact visible wallet as
one read-only, bounded inventory contract. The generic host rejects cycles and more than 100
contained nodes before JavaScript executes; the declaration fixes materialization to four levels.
Nodes at the fourth level are conservatively marked as possibly incomplete. Item details, recipes,
uses, and all gameplay actions retain their existing owners.
