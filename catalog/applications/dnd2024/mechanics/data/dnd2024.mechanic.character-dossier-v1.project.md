## Description

Composes the exact character-sheet v2 projection with canonical catalog identity and source
metadata for the recorded origin, class, features, and equipment definitions. It also exposes
explicitly pending origin traits and feature behavior without inventing their rules. The projection
is effect-free, bounded to four inventory levels, and receives only the audience-authorized
character selected by the host.

## Matches

show complete character dossier
inspect character origin traits features and inventory
read canonical character details with provenance
