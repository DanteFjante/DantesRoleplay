## Description

Completes one duration-ready Short or Long Rest by composing exact benefit owners, recording one
terminal completion, removing the active episode, and emitting one typed completion event. Every
benefit and lifecycle effect commits atomically.

## Matches

complete a short rest
complete a long rest
finish the rest and apply benefits
