## Description

Returns deterministic bounded canonical item instances and visible non-item contents below one
custody root.

Retained version-1 `dnd2024.item-definition` records can be inspected without converting them.
They are reported by their existing component identity; this read-only bridge grants no canonical
equipment activities, repairs no state, and preserves the same depth and quantity checks.

## Matches

inspect inventory
list carried items
