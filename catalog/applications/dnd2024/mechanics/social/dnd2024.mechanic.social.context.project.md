## Description

Projects the current social attitudes selected for one exact source actor. The host supplies the
player or DM audience outside mechanic input. Private records and reasons are omitted for players.

## Matches

show current social attitudes
why does this npc feel this way
show social relationship context

## Requirements

```json
{"roles":{"source":{"components":[],"includeRelationships":true,"relationshipComponents":[{"kind":"social-attitude.has-record","direction":"outgoing","targetComponentIds":["dnd2024.exploration.social-attitude"]},{"kind":"social-attitude.reason","direction":"outgoing","targetComponentIds":["game.core.world.fact"]}],"description":"The exact audience-authorized source actor."}},"inputSchema":{"type":"object","additionalProperties":false,"minProperties":0,"maxProperties":0},"elapsedTime":{"mode":"zero"}}
```

## Input

No caller input. The host binds the source actor and current authorized audience.

## Output

Returns current visible attitudes, reason facts, internal revision, and operation provenance. It is
effect-free and never returns dialogue, intent, acceptance, or a predicted NPC action.
