## Description

Calculates an exact whole-minute duration from one authored route profile, D&D travel pace,
terrain limit, terrain multiplier, and visibility multiplier. It validates the caller's observed
route profile and clock revisions and never changes state.

## Matches

calculate travel duration
resolve route pace and terrain duration
