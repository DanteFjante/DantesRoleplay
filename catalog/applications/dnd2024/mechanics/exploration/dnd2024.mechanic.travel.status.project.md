## Description

Projects one traveller's current location, one exact authored route profile, route availability,
the authoritative world clock, and the values still required to execute that route. It never
selects a pace, creates journey IDs, or treats the projection as travel authorization.

## Matches

show current travel status
is this route ready for travel
what remains before this journey can start
