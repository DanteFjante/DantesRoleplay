## Description

Administratively records or corrects one complete experience total without awarding or advancing.

## Matches

record character experience
correct character experience

## Requirements

```json
{"roles":{"subject":{"components":["dnd2024.character.experience"]}},"inputSchema":{"type":"object","additionalProperties":false,"required":["mode","total"],"properties":{"mode":{"type":"string","enum":["record","correct"]},"total":{"type":"integer","minimum":0,"maximum":2147483647}}}}
```

## Input and result

Pass exactly `{"mode":"record"|"correct","total":n}` with a nonnegative safe-integer total.
`record` requires absent state and `correct` requires a valid existing total. The mechanic proposes
one add or set effect; it does not award XP or advance a class.
