## Description

Runs the exact authored discovery activity and grants curse knowledge only to the named observer.
For a cursed magic-item source it also creates the existing observer-to-item knowledge record;
ordinary inventory remains unchanged.

## Matches

discover a hidden curse
identify a curse for an observer
