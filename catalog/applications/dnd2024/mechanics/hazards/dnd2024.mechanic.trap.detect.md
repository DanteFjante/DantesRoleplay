## Description

Runs the trap definition's exact detection activity through the verified ability-check mechanic.
Success records observer-specific knowledge. Failure returns no trap identity, name, definition,
effect, event, or next action.

## Matches

inspect for a trap
detect a hidden trap
search for hazards
