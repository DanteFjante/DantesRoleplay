## Description

Bind, discover, and remove one source-backed curse while keeping the hidden application and
observer-specific knowledge outside ordinary inventory projection.

## Instructions

1. Call `dnd2024.mechanic.curse.bind` only after the exact authored binding event is established.
   Bind creates a separate concealed application; it does not add curse data to the inventory item.
2. Call `dnd2024.mechanic.curse.discover` with the exact authored discovery activity. A success grants
   `curse.known-by` only to the named observer and, for a cursed item source, creates the existing
   observer-to-item `dnd2024.magic-item.knowledge` record.
3. Call `dnd2024.mechanic.curse.remove` only with an authored removal activity and a removal
   requirement the mechanic can verify. Unsupported predicates fail closed.

## Constraints

- Bind and removal events are scoped to the hidden application. Discovery is scoped to the observer.
- Do not reveal the definition name in ordinary inventory, context, notification, or bind narration.
- Retry with the same idempotency key; never duplicate a binding, knowledge edge, or removal.
