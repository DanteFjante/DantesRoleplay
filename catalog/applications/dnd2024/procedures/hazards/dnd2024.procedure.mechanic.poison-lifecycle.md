## Description

Apply, progress, and recover one source-backed poison without collapsing the poison application
into the Poisoned Condition.

## Instructions

1. Read the exact poison definition, its revision, delivery methods, onset, save activity, effects,
   and recovery activities. Stop if any required field is absent.
2. Call `dnd2024.mechanic.poison.apply`. Instantaneous onset requires the exact check and prepared
   consequences; measured onset requires empty consequences and records its due minute.
3. After another authorized action advances time, call `dnd2024.mechanic.poison.progress` for a due
   pending poison with the same revision and fingerprint.
4. Call `dnd2024.mechanic.poison.recover` only with an authored recovery activity and verified check.

## Constraints

- Retry with the same idempotency key. Never re-apply damage, Conditions, or recovery on a retry.
- A missing save, antidote, timing owner, or closed consequence is a stop condition.
- Read the current application and definition again after any stale-definition or not-due error.
