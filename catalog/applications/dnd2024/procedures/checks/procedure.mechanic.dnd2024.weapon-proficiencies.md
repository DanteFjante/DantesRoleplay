## Description

Records complete known Simple/Martial weapon-category proficiency membership.

## Instructions

Accept record/correct mode plus a canonical category subset; fix the SRD source and write only this component.

## Constraints

No class, weapon ID, Proficiency Bonus, attack, damage, or effect is accepted.
