## Description

Records or corrects one final Armor Class value, without claiming an incomplete AC-building formula.

## Instructions

Accept only `record|correct` mode and one positive safe-integer value; fix the source reference and add or replace exactly this component.

## Constraints

No caller-provided armor inputs, Dexterity, modifier, effect, source, attack, or result is accepted.
