## Description

Provides a deterministic read-only view of canonical item instances beneath one custody root.

## Instructions

Inspect the declared four-level containment projection and surface both canonical items and visible
unclassified contents in pre-order. Each item reports its definition identity, positive quantity,
equipment projection, and available definition facet component IDs. Read a reported facet through
its own procedure for detailed rules.

## Constraints

The view is bounded, proposes no effects, and infers no owner, accessibility, capacity, value,
weight, or permission. It does not recreate the removed monolithic item kind. Corrupt visible item
state fails closed.
