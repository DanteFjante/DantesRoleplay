## Description

Owns a closed consume-and-grant activity that consumes a descriptor-fixed positive quantity and
creates the descriptor-fixed ordinary item in the source stack's direct container.

## Instructions

Bind the source stack, owning definition, and exact granted definition, then supply only activity ID
and a new grant entity ID.

## Constraints

The caller selects only activity and new entity ID. Definitions fix quantity, granted definition,
name, and slot. Arbitrary effects, scripts, targets, costs, checks, currency, and magic are forbidden.
