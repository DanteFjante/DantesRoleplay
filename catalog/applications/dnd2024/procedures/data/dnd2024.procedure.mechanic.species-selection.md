## Description

Owns the pure character-creation read that derives exact Size, movement, creature-type, and grant
references from one bound canonical species definition.

## Instructions

1. Bind the exact species definition as the mechanic's `species` role. Never accept a definition or
   facet copy from input.
2. Use `{}` when the definition declares a default Size or only one allowed Size. Otherwise require
   exactly `sizeRef` with one allowed Size entity ID.
3. Preserve the returned species, creature-type, selected-Size, movement, and grant references in a
   creation plan. Apply grant references through their owning procedures.

## Constraints

This procedure grants no feature and performs no direct write. It does not reconstruct missing
species grants from a species name, legacy profile, or prose.
