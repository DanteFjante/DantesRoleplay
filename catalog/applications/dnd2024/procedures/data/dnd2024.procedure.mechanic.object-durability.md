## Description

Use `dnd2024.mechanic.object.durability.initialize` once for a definition-linked item, trap,
vehicle, or scenery object whose authored basis has concrete Armor Class, maximum Hit Points,
threshold, and damage responses. Use `dnd2024.query.object-durability` or the underlying read
mechanic before preparing a mutation.

## Instructions

`dnd2024.mechanic.object.damage` owns threshold and response resolution. When ordinary damage
reaches zero, its pinned destruction child atomically writes the destroyed state and every
applicable explicit effect in this order: unequip, close route, disable trap, remove general media,
remove world media. A caller must submit that exact list; omissions and additions fail closed.
Special resilience requirements other than `predicate.always` need a future verified predicate
owner and cannot be asserted by prose or caller confidence.

Stabilization clears active damage effects without restoring Hit Points. Repair restores bounded
Hit Points. Cost-free repair cannot rebuild a destroyed object. Rebuilding requires prior Slice 14
settlement receipt IDs; those owners, not this mechanic, consume materials and money and advance
time. The repair mechanic never advances time itself.

## Constraints

All retries use the public action idempotency contract. The transaction contains state effects and
declared events together, so a failure creates neither partial durability changes nor duplicate
events.
