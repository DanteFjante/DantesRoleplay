## Description

Turns immutable level-1 creation entitlements into executable rules or exact pending choices without
rewriting the creation record.

## Instructions

1. Inventory every unresolved entitlement from the immutable creation record.
2. Resolve choice-free behavior from current components and the active extension winner.
3. Return unresolved player or reviewer decisions with known values, missing values, and an exact next capability.
4. Record Magic Initiate only after two cantrips, one level-1 spell, and an allowed spellcasting ability are all supplied.
5. Adopt existing starting equipment only after a reviewer identifies the exact existing item instances for each owner; create no replacement items.

## Constraints

- Never invent spell choices, spellcasting ability, equipment correspondence, homebrew traits, or a weapon profile.
- A changed mechanic fingerprint must invalidate prepared execution rather than silently reuse it.
- Monk Martial Arts and Unarmored Defense are eligible only while their entitlement and equipment prerequisites remain true.
- The dossier must keep pending rules visible until their recorded configuration or reviewed adoption exists.
