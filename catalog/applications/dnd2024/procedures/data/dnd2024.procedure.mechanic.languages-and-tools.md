## Description

Owns two independent closed membership records for known languages and tool proficiencies.

## Instructions

Use explicit `record` or `correct` with only the named array. The writer rejects unknown or
duplicate IDs, canonicalizes order, fixes SRD provenance, and proposes one add/set effect. Empty is
known none; absence is unknown.

## Constraints

These are not generic proficiency arrays and store no grant, item, skill, check, crafting,
translation, Advantage, or derived result.
