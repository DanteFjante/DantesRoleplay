## Description

Records or corrects optional descriptive pronouns, appearance, and biography for an existing actor.

## Instructions

Use explicit `record` for absent state or `correct` for valid existing state. Supply at least one
trimmed nonblank profile field and no other keys. Each success adds or sets exactly one component.

## Constraints

This record does not establish display name, campaign membership, visibility, control, permission,
character-creation completion, or any game rule. Those checks must be composed by their owners.
