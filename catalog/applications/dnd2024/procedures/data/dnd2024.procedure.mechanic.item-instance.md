## Description

Defines a canonical campaign item instance with an exact immutable definition reference and a
positive quantity. Containment is its custody/location.

## Instructions

Use record once for an existing entity; it records quantity `1`. Use create-and-place for
administrative bootstrap, read for a derived view, and item transfer for ordinary movement. Use the
quantity procedure when creating or changing a count greater than one.

## Constraints

Identity is write-once and every canonical item instance has quantity. Administrative create/place
and move do no admission; normal custody moves use item transfer. Equipment, capacity, permission,
and derived totals are separate.
