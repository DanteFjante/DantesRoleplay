## Description

Owns one encounter turn's counted Action, Bonus Action, Reaction, interaction-use, and exact metric
movement-spending state, including diagnostics, start-of-turn creation, correction, and spending.

## Instructions

1. Source: `dnd2024.source.srd-5.2.1`, `Playing the Game > Actions; Bonus Actions; Reactions;
   Interacting with Objects; Combat > Your Turn`.
2. Keep exactly one `dnd2024.combat.turn-budget` on every created turn. The turn reference inside
   the component must identify its owner; a participant never owns a combat budget directly.
3. The writer accepts exactly `record|correct`, counted remaining resources, exact metric movement
   entries, and the interaction-use count. It derives the turn reference and proposes one add/set.
4. Start/advance create a fresh budget for the new turn. Base Speed, Conditions, resource costs,
   position, and movement execution remain separate owners; spending appends exact walk distance.
5. Action, Bonus Action, interaction, and movement require the participant's active turn. Reaction
   may spend the participant's latest turn budget off turn. Shared Condition prohibitions are
   evaluated before ordinary availability.

## Constraints

Resource counts, interaction uses, and movement-entry counts are bounded for deterministic runtime
safety. Every distance is a positive exact rational number of metres at spending time. No movement
maximum, Speed, encounter roster, position, resource cost, or event history is stored here.
