## Description

Owns accumulated XP and effect-free next-total-level threshold diagnostics.

## Instructions

Use explicit record/correct for the complete total. Read it with authoritative total character level
and derive only the exact next threshold or level cap.

## Constraints

XP is never spent on level gain. Award history/policy, authorization, class membership, HP, feature
grants, and actual level mutation are separate owners. Missing state is unknown, not zero.
