## Description

Identifies Trail Survival as an original, separately registered application whose authored catalog
and state remain isolated from other applications.

## Instructions

1. Select the `trail-survival` application before inspecting its catalog or state spaces.
2. Treat the effective activated application revision as catalog authority.
3. Treat a state space bound to that exact revision as runtime-state authority.

## Constraints

- This procedure declares no playable scenario, state schema, game mechanic, action, or outcome.
- Do not read or write another application's catalog or state as Trail Survival authority.
- Do not infer implemented gameplay from the application identity or this descriptive procedure.
