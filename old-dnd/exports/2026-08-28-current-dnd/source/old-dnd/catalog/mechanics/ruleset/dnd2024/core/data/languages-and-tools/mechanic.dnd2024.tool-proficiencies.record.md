## Description

Records or replaces a character's complete known D&D 2024 tool-proficiency state. It does not grant a tool from a background/class, create a physical tool, craft an item, or resolve a check.

## Matches

record tool proficiencies
set tool proficiencies
correct tool proficiencies
assign tool proficiency
