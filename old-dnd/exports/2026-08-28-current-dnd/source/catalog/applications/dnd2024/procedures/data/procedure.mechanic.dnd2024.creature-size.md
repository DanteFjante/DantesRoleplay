## Description

Stores one explicit SRD Size category on a creature for declared downstream readers.

## Instructions

Record exactly Tiny, Small, Medium, Large, Huge, or Gargantuan in lower case. Missing is unknown,
never Medium by default. The recorder is add-only.

## Constraints

Weight, dimensions, reach, Speed, carrying totals, token display, and temporary size changes are not
stored here.
