## Backlog exit rule

This backlog may be expanded as Caldris grows. A row becomes an implementation feature only after
its owner, ruleset class, source needs, IDs, schema meaning, transaction root, failure contract, and
acceptance evidence are closed in a dedicated dependency/implementation document.
